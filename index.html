About JSON X-Ray

JSON X-Ray is an online validator, reformatter, and structural family tree inspector for JSON. It allows you to see straight through deeply nested structures and explore parent-child relationships in one click.

Visual Structure Chart & Image Export

Instantly transform dense JSON data into an interactive horizontal curved graph. Pan, zoom, inspect individual variable nodes, and download the full structure as a high-resolution PNG or SVG image.

Variable Family Trees

Complex APIs often bury critical data across deep levels. Family tree lineage displays the full ancestor chain from root to leaf, immediate siblings, and children for any selected key.

Array Schema Archetypes

Instead of rendering 10,000 duplicate array rows, JSON X-Ray synthesizes the collection into a unified schema archetype, identifying optional fields and coverage ratios.
