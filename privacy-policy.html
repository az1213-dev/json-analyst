Privacy Policy

Last updated: September 3, 2024

Overview

JSON Analyst ("we", "our", or "us") is committed to protecting your privacy. This Privacy Policy explains our data practices for the JSON Analyst web application.

No Data Collection

JSON Analyst is a 100% client-side application. All processing happens in your browser. We do not collect, store, transmit, or analyze any of your JSON data.

What This Means:

  • Your JSON files never leave your computer
  • No data is sent to our servers (we don't have any servers)
  • No cookies are used to track your activity
  • No analytics or telemetry is collected
  • Your charts, validations, and exports are created only on your device

How JSON Analyst Works

When you use JSON Analyst, all operations occur locally in your web browser:

  • Validation: Your JSON is validated using JavaScript running on your machine
  • Formatting: Beautification and minification happen locally
  • Visualization: Charts and tree structures are generated in your browser
  • Export: Image exports (PNG/SVG) are created locally and downloaded to your device

GitHub Links

JSON Analyst includes a link to our GitHub repository. When you click this link, you leave JSON Analyst and visit GitHub.com. GitHub's privacy practices are governed by their own privacy policy.

Browser Data & Local Storage

JSON Analyst may use browser localStorage to persist your preferences, such as:

  • Your theme preference (light/dark mode)

This data is stored only on your device and never transmitted anywhere. You can clear this data anytime by clearing your browser's local storage.

Third-Party Dependencies

JSON Analyst uses the following third-party resources, all loaded from trusted CDNs:

  • Google Fonts: The Inter typeface is loaded from Google Fonts for consistent typography

When Google Fonts are loaded, Google may collect basic information about your request (IP address, user agent). Refer to Google's Privacy Policy for details.

Security

Since all processing happens on your device, the security of your data depends on your browser and device security. We recommend:

  • Using an up-to-date web browser with the latest security patches
  • Only using JSON Analyst on devices with appropriate security measures
  • Not leaving your device unattended while sensitive data is displayed

Open Source

JSON Analyst is open-source software available on GitHub. You can review our source code to verify our privacy and security practices. Visit our GitHub repository to see the code.

Changes to This Policy

We may update this Privacy Policy from time to time to reflect changes in our practices or for other operational, legal, or regulatory reasons. We will notify users of any material changes by updating the "Last updated" date at the top of this policy.

Contact Us

If you have questions or concerns about this Privacy Policy, please visit our GitHub repository and open an issue.

JSON Analyst is provided as-is for educational and professional use. By using this application, you agree to this Privacy Policy.
